# RM 第五次培训作业 - Godot 模拟器

## 操作说明

| 按键 | 功能 |
|---|---|
| W/S | 前进/后退 |
| A/D | 左移/右移 |
| 鼠标移动 | 云台俯仰+偏航 |
| 鼠标左键 | 发射子弹 |
| R | 重置（回到出生点，回满状态） |

## 功能列表

### 已完成
- [x] 步兵移动（WASD）+ 鼠标云台控制
- [x] 射击系统（冷却、弹药消耗、子弹碰撞）
- [x] 热量系统（射击升温、过热锁枪、自然冷却）
- [x] HUD：HP/弹药/热量/命中/比赛倒计时
- [x] HP/热量进度条可视化
- [x] 击中提示（TipLabel 自动消失）
- [x] 装甲受击扣血
- [x] 基地血量（打绿色方块扣血，归零显示）
- [x] 补给区（走进去回满HP/弹药/热量）
- [x] 比赛倒计时（180秒）
- [x] TCP 图像传输（端口9000，JPEG/PNG帧）
- [x] TCP 状态传输（端口9001，HP/弹药数据）
- [x] Python 接收端（recv_vision.py，实时显示画面）

## 规则简化说明

- 步兵初始 HP=100，弹药=40，热量=0
- 每发子弹伤害 10，热量 +15
- 热量超过 80 锁枪，降到 50 以下恢复
- 基地 HP=500，每发子弹扣 10
- 补给区自动回满所有状态
- 比赛时间 180 秒

recv_vision.py       # Python接收端

## 运行方式

1. 先启动 Python 接收端：`python3 recv_vision.py`
2. 用 Godot 4.7 打开 Main.tscn，按 F5 运行
3. Python 窗口会实时显示游戏画面
